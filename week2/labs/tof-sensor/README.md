# 실습 1·2 — 거리 센서

## 배선

| 센서 핀 | 케이블 색 | UNO Q | 오늘 |
|---|---|---|:---:|
| VIN | 빨강 | 전원 | O |
| GND | 갈색 | GND | O |
| SCL | 파랑 | **D21 / SCL** | O |
| SDA | 초록 | **D20 / SDA** | O |
| GPIO1 | — | 연결 안 함 | X |
| XSHUT | — | 연결 안 함 | X |

`Wire.begin()`이 기본 I2C 핀(D20/D21)을 자동으로 잡습니다. `pinMode()`로 따로 설정하지 않습니다.

## 실습 1 — 시리얼 모니터

1. App Lab에서 새 App 생성
2. 라이브러리 추가 → `Adafruit VL53L0X`
3. `sketch/sketch.ino` 내용 붙여넣기
4. Run → 시리얼 모니터 확인

### ✅ 합격
```
distance_mm=347
distance_mm=341
distance_mm=188      ← 손을 가까이 대면 숫자가 줄어야 한다
```

### 안 되면 이 순서로

| 증상 | 확인할 것 |
|---|---|
| `VL53L0X not found` 무한 반복 | ① VIN/GND ② SDA↔SCL 바뀌었는지 ③ `setClock`이 100000인지 |
| `out of range`만 계속 | 2m 넘게 비어 있음 / 검은 물체 / 렌즈 보호필름 |
| 값이 튐 | 형광등·햇빛 간섭, 렌즈 지문 |

### 먼저 끝났다면
- 손을 천천히 움직이며 **최소·최대 측정값** 기록
- **검은 물건 / 투명 컵 / 비스듬한 면**을 대보기 → 안 잡히는 걸 직접 확인
  (ToF는 빛을 쓰기 때문입니다. 이게 "그래서 카메라도 필요하다"의 이유입니다)

## 실습 2 — Bridge로 Python에 넘기기

1. `sketch.ino` 맨 아래 주석 해제
   ```cpp
   Bridge.notify("distance", distance_mm);
   ```
2. `python/main.py` 붙여넣기
3. 저장(Ctrl+S) 후 Run

### ✅ 합격
시리얼 모니터와 Python 로그에 **같은 숫자**가 동시에 흐르면 성공.

### 자주 나는 실수

| 증상 | 원인 |
|---|---|
| Python 로그가 조용함 | 주석 해제 안 함 / `"distance"` 문자열 오타 |
| 값이 뭉텅이로 몰려서 나옴 | `print()`에 `flush=True` 빠짐 |

> 💡 **`flush=True`가 왜 필요한가**
> 파이썬은 출력을 버퍼에 모아 뒀다가 한꺼번에 내보냅니다.
> 로그창에서 실시간으로 보려면 매번 강제로 내보내야 합니다.
