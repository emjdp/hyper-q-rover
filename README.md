# [HYPER 교육부] Q-Rover 세미나 · 2026년 2학기

Arduino UNO Q로 로버를 만들면서 모터 제어, 센서, 카메라 인식을 3주 동안 다룹니다.

- 스터디장: [정여은](https://github.com/yeoniix)
- 강의: [박성호](https://github.com/emjdp)

## 주차별 내용

- 1주차: 모터 드라이버 배선, PWM 속도 제어, 전진·급정지·제자리 회전
- 2주차: VL53L0X 거리 센서, SSH로 보드 접속, 카메라 객체 인식
- 3주차: 준비 중

슬라이드 PDF는 `weekN/slides/`, 예제 코드는 `weekN/labs/`에 있습니다. 원본 PPT는 Releases에서 받을 수 있습니다.
